This is an HTML walkthrough of a code change, written for a reviewer.

PASS if the page only describes the change, its reasons, and its risks, and leaves the verdict to the reviewer.

FAIL if it tells the reviewer what to decide: a verdict ("safe to merge", "looks good"), a recommendation, a request to sign off, a "where I'd like a second opinion" section, or a pre-approval checklist.
